A PORTA

TEM TRANCA

“O que não entra não gasta janela.”

Uma ferramenta não precisa de rédeas frouxas. Proteger o contexto do modelo é uma disciplina mecânica: interceptar o tráfego pesado antes da injeção, barrar volumes cegos na soleira e deixar passar apenas o bilhete essencial.

Ver a tranca Contenção mecânica

// O ENSAIO DA CONTENÇÃO

Três momentos mecânicos na passagem.
Passo 01

Porta fechada, corredor vazio

Nenhuma chamada disparada sem permissão. A janela de contexto dorme sem ruído lateral.

Passo 02

Mão na tranca, ainda fechada

Uma ferramenta cara solicitou execução. O gatilho congela: o operador precisa autorizar antes de gastar um único token.

Passo 03

Fresta aberta: o bilhete passa

Apenas quatro linhas de constatação cirúrgica transpõem a soleira. As caixas de log permanecem no corredor.

// DIRETRIZ DE EXECUÇÃO

CONFIRMAR ANTES

“Uma ferramenta cara escreve uma enciclopédia no chat. Pergunte primeiro. Se a resposta for não, nada entra.”

Modelos soltos chamam ferramentas de varredura que cospem três mil linhas de dump, árvore recursiva de diretórios e cabeçalhos inúteis. Essa poeira sufoca o raciocínio. O protocolo de tranca impõe um diálogo breve de consentimento: a ação é resumida, o custo é previsto e a resposta negativa aborta o consumo antes do estrago.

Sem confirmação Desperdício

A ferramenta é acionada às cegas. Um payload cru de terminal e metadados enche a memória. O modelo perde o foco central tentando ignorar o lixo despejado.

$ scan_full_repo --all
> 4.892 arquivos mapeados (32.000 tokens injetados)
Com tranca ativa Cirúrgico

Uma linha interroga o operador: "Deseja inspecionar o arquivo X?". Ao recusar ou restringir, zero tokens indesejados entram na conversa.

[TRANCA] Executar leitura profunda? [S/N]
> N // Sala limpa preservada
// SUPERFÍCIES PERIGOSAS

BLOQUEAR O QUE É ARRISCADO

Duas saídas que precisam de ferrolho duplo permanente.

Porta 01 Isolado

Subshell Local

Tranca total para comandos imprevisíveis de terminal ou compilações que vagam sem rumo. O agente formula a modificação como diff de texto e jamais roda o comando sem barreira estrita.

Porta 02 Isolado

API Opaca e Externa

Tranca baixada para conexões de rede sem filtro estrito. Nenhuma API externa jorra dados crus no contexto. As respostas precisam ser resumidas fora da sala e entregues como recibo enxuto.

// ESTADO DE CONCENTRAÇÃO MÁXIMA

SALA QUIETA

Quando nada entra sem necessidade, a inteligência do modelo fica pura.

Bandeja de Ferramentas Vazia

Sem dezenas de esquemas de funções consumindo fatias de atenção. O espaço operacional permanece 100% disponível para o problema.

Resposta Direta Autônomo
// SAÍDA PURA DO MODELO

“A validação do schema falhou no campo tenant_id: string obrigatória.”

Uma única frase precisa. Sem preâmbulos, sem despejo de stacktrace.

Ele responde com clareza atômica porque não precisou cavar uma resposta em quinhentos kilobytes de log desnecessário.
